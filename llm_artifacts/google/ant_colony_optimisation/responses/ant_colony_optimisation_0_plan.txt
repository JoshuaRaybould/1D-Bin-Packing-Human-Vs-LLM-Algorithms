1. Pre-processing: Sort all items by weight in descending order to prioritize difficult items. Store original indices to ensure the output matches the input requirements. 2. Initialize Parameters: Set alpha=1, beta=2, rho=0.1. Initialize the global best solution using a First Fit Decreasing (FFD) heuristic to provide a strong upper bound. 3. Pheromone Initialization (MMAS): Create an N x N pheromone matrix where pheromone[i][j] represents the affinity of item i and item j being in the same bin. Initialize all values to tau_max, calculated as 1 / (rho * best_bins_found). 4. Ant Construction Phase: For each ant, maintain a set of 'unplaced' indices. To build a solution: (a) Open a new bin. (b) Seed the bin with the largest available item from the unplaced list. (c) While the bin has remaining capacity: (i) Identify a candidate list of unplaced items that fit. To maintain speed, limit this list to the first 50 fitting items in sorted order. (ii) For each candidate, calculate the score: [Average pheromone with items already in the bin]^alpha * [weight of candidate]^beta. (iii) Use the q0 exploitation/exploration rule to select the next item. (iv) Move the selected item from unplaced to the current bin. (d) Repeat until all items are placed. 5. Pheromone Update (MMAS): (a) Evaporate pheromones: pheromone[i][j] *= (1 - rho). (b) Reinforce the Global Best: For every pair of items (i, j) that share a bin in the global best solution, increment pheromone[i][j] by 1 / best_bins_found. (c) Apply Bounds: Clamp all pheromone values between tau_min and tau_max, where tau_min = tau_max / (2 * n). (d) Periodically update tau_max based on the latest global best. 6. Time Management: Wrap the ant loop in a time check. Monitor elapsed time every iteration and exit if it exceeds 98% of the time_limit. 7. Final Output: Convert the best internal representation back to original indices and return the 'packing' and 'bin_weights'.
